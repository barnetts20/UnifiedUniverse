## How you make decisions while the owner is away

- If the design doc or DECISIONS.md answers it, follow that.
- If not, choose the option that is **reversible, verifiable, and closest to the design's intent**. Record it in `docs/DECISIONS.md` as D-100 onwards, with the fields used there, including *Reroll impact*.
- **Stop and record instead of acting** only for things that cannot be undone or that touch anything outside the new plugin: deleting files you did not create, modifying UltraLargeScale, changing project-wide config, engine settings or other plugins, force-pushing, rewriting history. Put such items in `REVIEW_TONIGHT.md` under "Needs your decision".
- **Time box.** If one item has resisted for about 45 minutes, record what you tried and what you suspect in the progress log, mark it blocked, and move to the next item. Come back later only if time remains.

## The plan

Work through these phases in order. Each ends with a **gate**: run `verify_all`, commit if green, log it. Approximate times assume a 10–12 hour run and are guidance, not deadlines.

### P1 — Scaffold, coordinates, harness (about 2 h)
- Plugin descriptor and the four modules from D-001, with shader directory mapping guarded against double registration (lesson #33). Build.cs files with only the dependencies each module needs.
- `Source/UniCore/`: `UniCoord.h` (`FUniCoord`, `FUniDelta`, `FUniCellKey`, all operations in the coordinate spec), engine-agnostic.
- `Shaders/Private/Core/UniCoord.ush` + `UniHlslShim.h`, written in the shared subset (D-015).
- `Tools/UniVerify/` harness, Python oracle and coordinate fuzz tests.
- UE-side adapters: `FUniCoord` as a BlueprintType wrapper, hex string serialisation.
- **Gate:** Tier 1 coordinate checks green. If UE is available, the plugin builds.

### P2 — Seeds, cell keys, windows, level assignment, photometry (about 1.5 h)
- `UniSeed` (port `ProcSeed` exactly, including the Avalanche finalizer, lesson #14), C++ and `.ush`.
- Level windows: toroidal slots, entering/exiting diff, coarse-to-fine ordering, velocity LOD.
- Relevance radius → level, using D-010 and D-011 constants.
- f(r), apparent magnitude, fade, sensitivity scaling.
- **Gate:** all Tier 1 checks green.

### P3 — Generation reference pipeline (about 3 h)
- Archetype, emitter and field data model as plain structs in UniCore (UE `UUniArchetype` assets wrap them later). Follow the archetype pipeline order (lesson #15) and the seed channel rules (#14).
- Analytic stand-in fields (D-012), written once in the shared subset.
- Cell integrals, Poisson counts, placement (D-013), luminosity slicing (D-014), contributor registration and gather (D-004), anchors and suppressors.
- Periodic UniVol test volume generator and a baked-field path with mip integrals and mip-descent placement (D-007).
- `univerify gen` and the Tier 2 checks.
- **Gate:** Tier 2 green on at least two scenes: a cosmic-web-to-galaxy scene and a galaxy-to-star scene.

### P4 — Projection and the reference renderer (about 2 h)
- Project-and-cull logic as a shared core: exact relative vector from hi/lo cell deltas, f(r), magnitude cull, fade, promotion candidate test with hysteresis.
- `univerify render`, HUD, flythrough contact sheets.
- Jitter, ordering, occlusion and flythrough checks (Tier 3). Look at the images yourself and write what you see in the report.
- **Gate:** Tier 3 green.

### P5 — Unreal integration (about 3 h, as far as the environment allows)
- `UnifiedUniverseRender`: RDG compute passes for generation and project-and-cull, using the shared cores. Indirect sprite draw in a backdrop pass with the scene-depth test. Composite pass. Scene view extension, with every hook in `UniRenderHooks.cpp` (D-006). Follow lessons #19–#28 exactly: 16-byte GPU structs with `static_assert`s, 2D dispatch wrapping, readbacks allocated on the calling thread, render commands enqueued from the game thread, single by-value payloads, fail-closed slot blanking.
- `UnifiedUniverse`: `UUniSubsystem` with camera, windows driving generation, and promotion readback stubs.
- A test map and a minimal actor that drives a flythrough, so the owner can see it tonight with one console command.
- UE Automation tests wrapping the UniCore tests, runnable with `-nullrhi`.
- **Gate:** whatever Tier 4 the environment allows. Everything else is listed in REVIEW_TONIGHT with exact steps.

### P6 — Stretch, only if all gates above are green
In this order: sensitivity (global Δm, then the ping shell) in the reference pipeline → promotion handoff and local anchor in UE → UniVol editor importer → volumetric proxy raymarch.

## Engineering rules (also in plugin_seed/CLAUDE.md)

- Produce complete files, not snippets.
- Absolute positions are never `FVector` or float. Use `FUniCoord`, or integer cell plus fraction (lesson #19).
- Render and placement evaluate the same field source. There is no CPU fallback field (lesson #1).
- Every GPU struct is a multiple of 16 bytes with no straddling float3, guarded by `static_assert` on the C++ side (lesson #20).
- Seeds: add channels, never reuse or repurpose them (lesson #14).
- Fades are render-only and never affect generation (lesson #12).
- Never modify UltraLargeScale.
